# 录音调频网站

轻量练歌录音网站：戴上耳机就能实时听到「美化后」的声音（EQ + 混响耳返），并完成伴奏录音、裁剪、音量调节、导出与本地工程保存。

## 已实现（对应 PRD v1.3 MVP）

- F1 伴奏导入：本地 mp3 / m4a / wav / aac（浏览器解码）
- F2 录音：1 伴奏轨 + 1 人声轨，边播伴奏边录人声
- F3 实时监听：耳机实时听到 EQ + 混响效果，可开关，蓝牙设备会提示高延迟
- F4 参数式 EQ：低架 / 中低频峰 / 中高频峰 / 高架，各段可调频率、增益、Q
- F5 混响：4 预设 + 可调 Decay / Pre-delay / Mix / Size
- F6 裁剪：时间轴起止点裁剪
- F7 音量：人声轨、伴奏轨各自独立音量
- F8 导出：48kHz / 24bit WAV（单声道或双声道，跟随声道选择；离线渲染，人声带 EQ + 混响，混合伴奏）
- F9 工程保存：本地 IndexedDB 保存（干声 + 参数元数据），可继续编辑，非破坏式
- F10 / F11 外接麦克风 / 蓝牙耳机：依赖浏览器设备能力，含延迟与设备显示
- 声道选择：单声道（默认）/ 双声道切换，单声道时伴奏自动下混为单声道，导出为单声道 WAV
- 分轨界面：伴奏、人声分为两条独立轨道，共享同一时间轴窗口（唱针/播放头同步），默认窗口 5 分钟；录音/播放时播放头实时跟随滚动
- 删除 / 撤销：伴奏轨、人声轨可单独删除；`Ctrl/Cmd+Z` 撤销最近的删除、录音、导入、参数调整等操作（最多保留 50 步）
- 选区循环：以裁剪起止点作为循环区间，点亮「循环」后在区间内反复播放
- 输入电平表 + 总线路由限幅：顶栏显示麦克风输入峰值，实时监听与导出都经过总线路由限幅，防止爆音

## 运行方法

本机已装 Node.js，无需安装任何依赖：

```powershell
cd C:\Users\SYLY\Documents\ChatGPT\音频调频
node server.js
```

用 **Chrome 或 Edge** 打开：

```
http://localhost:8000
```

> 必须走 `localhost`（安全上下文），不能直接双击 HTML 打开。
> 麦克风权限首次启动引擎时授权；有线耳机耳返体验最佳。

## 使用流程

1. 点「启动引擎」，授权麦克风
2. （可选）导入伴奏 → 播放
3. 调节 EQ / 混响 / 音量，戴耳机实时监听
4. 点「开始录音」→ 唱 → 「停止录音」（采集干声）
   - 已有录音时再次点击录音，会从当前唱针位置做「插入覆盖」：只覆盖重叠时间段，旧人声其余部分保留
5. 「设为录音范围」或手动填裁剪起止点
6. 「导出 48kHz / 24bit 立体声 WAV」
7. 填工程名 → 「保存工程」，下次可「载入」继续编辑

> 时间轴操作：滚轮缩放视图大小（以鼠标位置为中心）、`Shift`+滚轮横向滚动、双击复位到 5 分钟默认窗口并重新跟随；播放/录音时播放头自动跟随，手动拖动定位或横向滚动会暂停跟随。

## 文件结构

```
server.js           本地静态服务器（Node 内置模块，无依赖）
index.html          界面
style.css           样式
app.js              音频引擎：录音 / 伴奏 / EQ / 混响 / 导出 / 工程
recorder-worklet.js 干声采集 AudioWorklet 处理器
```

## 技术说明 / 已知边界

- 录音采干声使用 `AudioWorkletNode`（替代已废弃的 `ScriptProcessorNode`）
- 混响为「确定性程序生成的立体声脉冲响应 + ConvolverNode」，包含早反射与高频衰减；单声道模式自动使用单声道 IR，双声道模式使用双声道 IR
- 延迟读数是 `baseLatency + outputLatency` 的估算值，真实往返延迟需声卡回环实测
- 伴奏与导出均经 `OfflineAudioContext` 在 48kHz 渲染，浏览器会自动重采样来源音频
